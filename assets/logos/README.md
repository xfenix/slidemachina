# Логотип slidemachina

Основной вариант — знак со стопкой слайдов и надписью Plus Jakarta Sans SemiBold (600). Надпись переведена в кривые: устанавливать шрифт не нужно. Фон всех SVG прозрачный.

| Файл | Где использовать |
| --- | --- |
| `logo-light.svg` | Полный логотип на светлом фоне |
| `logo-on-dark.svg` | Полный логотип на тёмном фоне |
| `icon-color.svg` | Синий знак без надписи: иконки и аватар репозитория |
| `icon-dark.svg` | Одноцветный тёмный знак |
| `icon-white.svg` | Белый знак на тёмном фоне |

В `archive/` сохранены исходный логотип в двух цветовых версиях, первый эскиз со стопкой слайдов и вариант с Syne. Вариант Plus Jakarta Sans выбран основным и лежит в корне этой папки.

Эти файлы — исходники для README, аватара репозитория и других мест вне слайдов. В демо логотип рисует компонент `examples/demo-presentation/slidemachina-logo.tsx`. Если меняете логотип, обновите и его. Примеры с общей темой и шаблон новой презентации используют собственные логотипы.

Шрифт: [Plus Jakarta Sans](https://github.com/google/fonts/tree/main/ofl/plusjakartasans), лицензия SIL Open Font License 1.1, см. `font-license.txt`. Архивный Syne распространяется по той же лицензии, см. `archive/syne-font-license.txt`.
